# Quick Bar Pro releases

Download the file for your computer from the [Releases page](https://github.com/Rupesh9369/test-if/releases).

- **Windows:** `QuickBarPro-win-1.0.1.zxp` (release `v1.0.1-win`)
- **Mac:** `QuickBarPro-mac-1.0.1.zxp` (release `v1.0.1-mac`)

Install the `.zxp` with a ZXP installer (for example ZXP Installer or Anastasiy's Extension Manager), then restart After Effects and open Window > Extensions > Quick Bar Pro.
